# Tokey brand notes

Use **Tokey** in prose and **TOKEY** for the block wordmark. A benchmark is a
**Tokey Run**.

The mascot and wordmark source files are `assets/tokey-mascot.txt` and
`assets/tokey-wordmark.txt`. Keep their characters and whitespace unchanged.

```text
 (\_/)
(='.'=)
(")_(")
```

The interface uses a fixed dark palette: `#05090d` background, `#0a1318`
panels, `#18323d` edges, `#d0d0d0` text, `#71848b` muted text, `#3bfb1b`
green, `#55ead4` cyan, `#3fc2e0` blue, and `#0b6974` teal.

The completion glint is display-only. It must never alter or clip the base
artwork, and reduced-motion mode shows the plain green mark.
